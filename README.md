## ✨ عن المشروع

**ZONA** متجر أونلاين فاخر للانجري والبيجامات الحريمي، مبني بـ **Next.js 16**، بواجهة عربية كاملة (RTL)، بألوان منصة منارة (تيل `#0d9488` • نيفي `#0e2c4e` • دهبي `#f59e0b`)، ووضع **لايت / دارك**، وأنيميشن وشيمر في كل سكشن وانت نازل، وحسابات للعملاء، و**Admin Studio** كامل فيه **CRUD على كل حاجة + حساب الأرباح**.

### 🔐 الدخول

- صفحة الدخول واحدة للكل: `/login` — بيانات الأدمن بتدخّل لوحة التحكم، وبيانات العميلة بتدخّل "حسابي".
- لوحة التحكم: `/admin`
- اعمل ملف `.env.local` وحط فيه بيانات الأدمن (**لازم تتغير قبل النشر**):

</div>

```env
ADMIN_EMAIL=you@yourstore.com
ADMIN_PASSWORD=your-strong-password
ADMIN_SECRET=a-long-random-string
```

<div dir="rtl">

### 💾 البيانات

- كل البيانات (منتجات، طلبات، عملاء، شحن، كوبونات…) في `data/db.json` وبتتعمل تلقائيًا أول تشغيل ببيانات تجريبية.
- كلمات سر العملاء متخزنة متشفرة (scrypt)، والجلسات بكوكيز موقّعة.
- الصور المرفوعة من الأدمن في `data/uploads`.
- امسح مجلد `data` عشان ترجع للبيانات الأصلية.
- الاستضافة لازم تكون **سيرفر Node** (VPS / Railway / Render) عشان الملفات تتحفظ.

## 🗂️ هيكل المشروع

</div>

```text
src/
├─ app/
│  ├─ (store)/          # Home, shop, product, checkout, order, track, login, register, account
│  ├─ admin/            # Admin Studio (dashboard, orders, products, customers, …)
│  ├─ api/              # Orders, coupons, customer auth, admin CRUD, upload
│  └─ uploads/[file]/   # Serves admin-uploaded images
├─ components/          # Header, ticker, cart, footer, product cards, motion helpers
│  ├─ home/             # Hero, sections, showcase (bridal, features, reviews)
│  ├─ auth/             # Login, register, account
│  └─ admin/            # Shell, nav, CRUD page, dashboard, UI kit
├─ lib/                 # JSON DB, auth (HMAC cookies + scrypt), orders, social, seed
└─ proxy.ts             # Protects /admin/*
```
